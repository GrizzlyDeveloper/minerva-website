ЭКСПЕРИМЕНТ / FABRIC 1.21.11

Пауза между сессиями.
Возвращение из трея.

После выхода в главное меню игра может оставаться запущенной в памяти и скрываться в трей. Верните её без полного перезапуска JVM. В ожидании рендер ограничен до 2 FPS.

Только для поддерживаемой Fabric 1.21.11. Включается вручную. Процесс игры остаётся в памяти — снижение расхода ОЗУ не гарантируется.

По желанию: подготовка игры после входа в Windows или по расписанию. Обе настройки включаются отдельно.

02ЛАУНЧЕР

Разные миры.
Одна цельная система.

Vanilla и Fabric в отдельных инстанциях: у каждой свои миры, моды и настройки, включая версию Fabric Loader. Назначьте профиль запуска по умолчанию каждой сборке и запускайте разные инстанции одновременно под разными профилями.

Своя сборкаVanilla или Fabric

ВместеПараллельные запуски
03ВОЗМОЖНОСТИ

Всё для вашей сборки.
До и после запуска.

От установки первого мода до восстановления сборки. Эти возможности уже доступны в публичной бете.

01 / КОНТЕНТ

Два каталога. Одно место.

Моды, ресурспаки и шейдеры из Modrinth и CurseForge в едином каталоге с метками источника. Смотрите популярное без поискового запроса и листайте страницы результатов. Импорт .mrpack создаёт новую инстанцию; доступны и локальные файлы. CurseForge-модпаки пока не поддерживаются.

Modrinth · CurseForge · .mrpack
02 / ВЕРСИИ

Обновляйте с возможностью отката.

Устанавливайте подходящую версию одним нажатием или выбирайте её вручную. Проверяйте зависимости перед запуском, обновляйте контент и возвращайтесь к сохранённой версии, если обновление не подошло.

Выбор версии · обновление · откат
03 / ЗАПУСК

Готовые файлы — сразу в дело.

По вашему выбору — запуск из уже подготовленных локальных файлов без повторной сетевой проверки файлов игры. Для лицензионного профиля по-прежнему нужна действующая Microsoft-авторизация. Подходящая Java 21 для современных версий Minecraft устанавливается автоматически, если её нет.

Локальный запуск · Java 21
04 / ДИАГНОСТИКА

Больше контекста о вылете.

Диагностика показывает свидетельства из логов и историю вылетов. После успешного запуска старый краш остаётся в истории, а не в текущих проблемах. Живые логи доступны отдельно для каждой инстанции, в том числе при параллельной игре.

Свидетельства · история · живые логи
05 / ФАЙЛЫ

Восстановите. Возьмите с собой.

Repair проверяет и восстанавливает управляемые файлы без намеренного удаления миров, конфигов и пользовательского контента. При ZIP-экспорте вы выбираете содержимое и можете включить дополнительные папки — например, метки Xaero.

Repair · ZIP с выбором папок
06 / КАЖДЫЙ ДЕНЬ

На вашем языке. Под рукой.

Русский и английский интерфейс: выберите язык при установке или смените его в настройках. Пока игра запущена, Minerva работает через системный трей. Обновления лаунчера доступны через GitHub Releases.

RU / EN · трей · обновления
