Кому подходит и что требуется

Закройте запущенные игры. Общий мир открывайте только в одной игре одновременно.

Порядок действий

  1. Откройте настройки общей библиотеки папок для нужной сборки.
  2. Выберите schematics, emotes, sounds/sound, saves, screenshots или разрешённую собственную папку.
  3. Проверьте выбранную библиотеку и подтвердите подключение. Существующие локальные файлы сохраняются отдельно; миры автоматически не объединяются.
  4. Перед началом игры проверьте содержимое папки. Для независимой копии используйте полное клонирование или ZIP-экспорт.
  5. Для возврата локальной папки отключите её от библиотеки при закрытой игре.

Ожидаемый результат

Подключённые сборки используют одну библиотеку. Удаление сборки не удаляет саму библиотеку.

Если не получилось

Изменение подключения блокируется во время работы игры. Общая папка не является резервной копией.

Безопасное восстановление

Не удаляйте библиотеку для отключения сборки. Отключите связь штатным действием и проверьте возвращённые локальные данные.
