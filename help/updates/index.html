Кому подходит и что требуется

Windows x64. Stable — основной канал; preview может содержать предварительные версии. Совпадение текущих номеров каналов не делает их разными сборками.

Порядок действий

  1. Посмотрите текущую версию в лаунчере и заметки в «История обновлений».
  2. Выполните предложенное лаунчером обновление либо скачайте официальный установщик с главной.
  3. Закройте игру перед заменой файлов приложения. Дождитесь завершения установки.
  4. Откройте Minerva и проверьте номер версии, список сборок и простой запуск до изменения игровых файлов.

Ожидаемый результат

Лаунчер обновлён; существующие сборки проверены отдельно. Скачивание файла само по себе не доказывает успешное обновление.

Если не получилось

При сбое сети повторите загрузку. При ошибке подписи не обходите проверку. Старый GitHub feed может быть мостом на VPS, а не местом хранения установщика.

Безопасное восстановление

Сохраните данные и скачайте официальный установщик повторно. Перед откатом проверьте совместимость данных; не заменяйте файлы миров старой копией без собственного бэкапа.
