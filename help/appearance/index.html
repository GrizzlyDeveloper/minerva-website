Скины, плащи и внешность Minerva

Официальный облик Microsoft и переопределение Minerva настраиваются отдельно.

  • Minerva 0.4.46
  • 2026-11-01
  • Проверено по исходникам

Кому подходит и что требуется

Компонент Minerva: Fabric 1.21.1, 1.21.4, 1.21.10, 1.21.11, 26.2 и 26.3. Применение HD-скина требует Minerva Premium.

Порядок действий

  1. Для Minerva-скина откройте «Скины» в личном кабинете сайта. Официальный облик Microsoft меняется в лаунчере или профиле Minecraft.
  2. Выберите официальный скин/доступный плащ Microsoft либо локальный файл для библиотеки.
  3. Для отдельного скина Minerva войдите в Minerva и выберите нужный профиль. Перед изменением проверяется сессия.
  4. Для HD-скина используйте Premium. Доступны два сохраняемых слота по никам.
  5. Проверьте внешний вид и переключатели слоёв на поддерживаемом клиенте с компонентом.

Ожидаемый результат

Minerva-скин является отдельным переопределением; официальный Microsoft-скин не заменяется. Просмотр доступен всем пользователям компонента.

Если не получилось

Вход Microsoft не заменяет вход Minerva. Если игра уже запущена, для подключения к сеансу Minerva может понадобиться перезапуск сборки. Если элитры пропадают при своём плаще Minerva, обновите лаунчер до 0.4.46 или новее и полностью закройте и заново запустите Minecraft. Рисунок плаща не заменяет текстуру крыльев: компонент сохраняет оригинальные элитры или использует стандартные. Исправление относится к поддерживаемым версиям Fabric.

Безопасное восстановление

Сохраните исходный PNG. Для снятия переопределения войдите в соответствующий аккаунт Minerva.
