Кому подходит и что требуется

Личное облако требует входа Minerva. Ссылка друга должна содержать полный секретный fragment. Открытие чужой ссылки само по себе не занимает облачный слот.

Порядок действий

  1. Выберите «Сборки» → «Импорт» → «Мои облачные сборки» либо «Ссылка друга».
  2. Выберите сохранение или вставьте полную ссылку и нажмите «Открыть сборку».
  3. Проверьте манифест, версии и отсутствующие файлы. Выберите компоненты и target, сохранив данные существующей цели заранее.
  4. Запустите установку и следите за прогрессом файлов. Используйте повтор при временном сбое.
  5. Если установка незавершена, продолжите в тот же target. Проверьте запуск после обязательных файлов.

Ожидаемый результат

Файлы подготовлены в выбранной цели. Свой облачный слот используется только при отдельном явном сохранении копии.

Если не получилось

Пропуск обязательного файла не делает сборку готовой. Ссылка может быть отозвана; обновление исходной облачной сборки не меняет снимок по ссылке.

Безопасное восстановление

До установки в существующую цель сохраните mods/config/saves. Не удаляйте успешные файлы при временной сетевой ошибке; сохраните список недостающего.
