Перенос из Modrinth

Minerva создаёт независимую копию поддерживаемых игровых данных, сохраняя оригинал.

Кому подходит и что требуется

Закройте Minecraft в Modrinth. Нужны место для копии и резерв свободного места; неизвестные метаданные требуют ручного выбора. Реальную сборку сначала сохраните отдельно.

Порядок действий

  1. Откройте «Сборки» → «Импорт» → «Из другого лаунчера».
  2. Выберите обнаруженную сборку Modrinth. Для нестандартного расположения укажите папку вручную.
  3. В предварительном просмотре проверьте исходную gamePath, версию Minecraft/загрузчика, включённые и непереносимые папки, размер.
  4. Подтвердите «Minecraft в исходном лаунчере закрыт» и нажмите «Скопировать в Minerva».
  5. После копирования запустите новую сборку: Minecraft, Java и библиотеки подготовит Minerva. Сравните миры, моды и настройки.

Ожидаемый результат

Оригинал не перемещается и не удаляется. Учётные записи, launch hooks, чужие Java и команды запуска не импортируются.

Если не получилось

Если обнаружение не нашло переносимую/новую структуру, выберите каталог вручную. При ошибке изменения источника закройте игру и начните копирование заново.

Безопасное восстановление

Не удаляйте исходную сборку до проверки копии. Прерванный импорт папки перезапускается с источника; это другой механизм, чем продолжение установки .minerva.
