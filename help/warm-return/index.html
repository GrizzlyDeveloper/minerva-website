Warm Return и полный выход

Warm Return сохраняет поддерживаемый клиент в памяти для возврата; RAM продолжает использоваться.

Кому подходит и что требуется

Fabric 1.21.1, 1.21.4, 1.21.10, 1.21.11, 26.2 и 26.3. В новых поддерживаемых сборках включён по умолчанию; сохранённые настройки не меняются.

Порядок действий

  1. Проверьте Warm Return в настройках поддерживаемой сборки. Опцию можно отключить.
  2. Запустите игру и проверьте доступность режима. Перед ожиданием выйдите из мира/сервера к безопасному экрану.
  3. Используйте доступное действие возврата в лаунчер, затем вернитесь в сохранённый клиент.
  4. Следите за памятью: Minecraft остаётся процессом в RAM.
  5. Для освобождения ресурсов используйте полный выход из игры, а не только скрытие окна.
  6. Пока слот Warm Return занят, дополнительные игры запускаются обычно. Для Voxy используйте отдельные папки сборок.

Ожидаемый результат

Возврат возможен без нового холодного запуска поддерживаемого клиента. Активную сессию мира/сервера нельзя считать безопасно завершённой скрытием.

Если не получилось

Если версия/загрузчик не поддерживаются, режим недоступен. Сохранённый клиент может занимать значительную память; это не бесплатное ускорение FPS.

Безопасное восстановление

При проблеме полностью закройте Minecraft и отключите опцию для этой сборки. Убедитесь, что процесс игры завершён, перед заменой файлов/профиля.
