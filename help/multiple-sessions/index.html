Несколько игровых окон и Voxy

Запускайте разные профили и разделяйте данные модов, которым нужен эксклюзивный доступ.

Кому подходит и что требуется

Для одновременного входа на один сервер нужны разные игровые профили и разрешение правил сервера. Лаунчер не отменяет лимиты сервера.

Порядок действий

  1. Выберите профиль нужной сборки и запустите игру.
  2. Повторный запуск обычной сборки требует подтверждения. Пока Warm Return занят, дополнительные окна запускаются обычно.
  3. Если установлен Voxy, закройте игры и создайте отдельную копию сборки для твинка. «Только контент» копирует моды и ресурспаки без базы .voxy.
  4. Назначьте копии другой игровой профиль и запустите отдельные сборки.

Ожидаемый результат

Клиенты используют разные профили, а копии сборок — разные папки данных. Не открывайте один локальный мир в двух процессах.

Если не получилось

RocksDBException / Failed to create lock file в .voxy означает невозможность открыть базу Voxy. В сообщении о занятости другим процессом причина — общий доступ к той же базе.

Безопасное восстановление

Не удаляйте LOCK работающей базы. Закройте игры и разделите папки сборок. Для другого зависания сохраните latest.log и crash-report.
