Настройки сборки и общий источник

Проверьте источник настроек перед изменением: связанные сборки могут использовать общие параметры.

Кому подходит и что требуется

Назначение источника настроек и копирование игровых данных — разные операции. Закройте игру и сохраните config/options перед их заменой.

Порядок действий

  1. Откройте настройки нужной сборки из её дополнительных действий.
  2. Посмотрите, является ли она источником или использует настройки другой сборки. Сверьте это с отметкой на карточке.
  3. Измените Java/память только после проверки выбранного источника. Не назначайте общие настройки случайно рабочим сборкам.
  4. Для переноса игровых options/config сначала сделайте копию файлов и переносите только совместимые параметры при закрытой игре.
  5. Запустите сборку, проверьте применённые настройки, затем отдельно проверьте другие связанные сборки.

Ожидаемый результат

Источник общих настроек выбран осознанно; локальные файлы не считаются автоматически совместимыми между версиями.

Если не получилось

Похожая настройка в двух версиях может иметь другой формат. Копирование options.txt целиком может затронуть графику и управление.

Безопасное восстановление

Верните сохранённые config/options при закрытом Minecraft. Для биндов используйте отдельный механизм восстановления с предпросмотром, а не замену всего options.txt.
