Кому подходит и что требуется

Minerva 0.4.28. Для загрузки известных файлов нужна сеть. Проверка не гарантирует отсутствие всех runtime-конфликтов или ошибок самого мода.

Порядок действий

  1. На карточке выберите «Исправить» и дождитесь отчёта управляемых файлов.
  2. Откройте группу проблемы. Если нужный Fabric API или другая библиотека выключена, включите её.
  3. Если зависимость известна и доступна, используйте предложенную установку. Сверьте версию Minecraft/загрузчика.
  4. Для дубликатов и несовместимости сохраните копию и отключите конфликтующие файлы по одному.
  5. Повторите проверку и запуск. Неизвестную зависимость решайте вручную по сообщению мода.

Ожидаемый результат

Исправлены конкретные выявленные проблемы. Игнорирование предупреждения не считается исправлением.

Если не получилось

Группировка нескольких модов по одной библиотеке не означает несколько разных ошибок. Отсутствие известного файла в каталоге требует ручного решения.

Безопасное восстановление

Перед заменой сохраните моды, config и миры. Если после ремонта стало хуже, верните последнюю изменённую группу и приложите обезличенный отчёт разработчику.
