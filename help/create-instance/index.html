Создание сборки: версия, загрузчик, Java и память

Каждая инстанция хранит игровые данные отдельно; выбирайте загрузчик под свои моды.

Кому подходит и что требуется

Доступные сочетания Minecraft и загрузчика определяются каталогом. Поддержка одного Fabric-релиза не означает поддержку всех исторических версий.

Порядок действий

  1. На экране «Сборки» нажмите «+ Новая сборка».
  2. Укажите имя, версию Minecraft, загрузчик и доступную версию загрузчика.
  3. Проверьте источник общих настроек и параметры Java/памяти. Для независимых настроек используйте собственный источник.
  4. Создайте сборку и нажмите «ИГРАТЬ». Дождитесь установки runtime и проверьте главное меню.
  5. В 0.4.53 можно нажать «Играть» у второй сборки во время подготовки первой. Запрос попадёт в очередь. Кнопка остановки отменяет запрос в очереди или подготовку текущего запуска. Текущая запись кеша может завершиться до отмены.

Ожидаемый результат

Сборка имеет собственную папку и подготовленный runtime после успешного первого запуска.

Если не получилось

Мод для Forge не становится Fabric-модом при смене загрузчика. Неподходящая Java и чрезмерная память могут мешать запуску; диагностируйте по логу.

Безопасное восстановление

Перед сменой версии сохраните saves/config/options. Для эксперимента создайте отдельную сборку, чтобы исходная оставалась доступна.
