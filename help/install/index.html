Установка Minerva на Windows

Скачайте установщик Windows x64 с главной и проверьте его происхождение до запуска.

Кому подходит и что требуется

Нужны Windows x64, свободное место для лаунчера и игры, доступ к сети для первой установки. Объём RAM и Java зависят от версии Minecraft и сборки; фиксированный универсальный минимум не заявлен.

Порядок действий

  1. Откройте раздел «Скачать» на главной. Сверьте версию, дату, размер и SHA-256.
  2. Скачайте установщик с minervalauncher.com и сохраните существующие миры перед сменой установки.
  3. Запустите установщик и выберите каталог. Не отключайте защиту Windows ради установки.
  4. Откройте Minerva. Затем настройте игровой профиль и создайте сборку по стартовому гайду.

Ожидаемый результат

Открывается экран «Сборки». Само открытие лаунчера ещё не означает, что Minecraft установлен.

Если не получилось

Если метаданные загрузки недоступны, повторите запрос позже. Подпись Tauri проверяет обновления и не равна Windows Authenticode: SmartScreen может предупреждать о неизвестном издателе.

Безопасное восстановление

При несовпадении хеша не запускайте файл, скачайте его заново. Сохраните папки сборок перед удалением или переустановкой лаунчера.
