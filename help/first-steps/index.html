Кому подходит и что требуется

Установлена Minerva 0.4.28 для Windows x64. Для первоначальной подготовки Minecraft нужна сеть; Microsoft-профиль требует соответствующего доступа к игре.

Порядок действий

  1. В «Профиль» добавьте Microsoft или локальный игровой профиль. Аккаунт Minerva для облака настраивается отдельно.
  2. Откройте «Сборки» → «+ Новая сборка». Выберите Minecraft и доступный загрузчик, задайте имя.
  3. Проверьте память и Java в настройках сборки. Не выделяйте игре всю память компьютера.
  4. Нажмите «ИГРАТЬ», дождитесь подготовки файлов и проверьте главное меню Minecraft.
  5. Закройте Minecraft. Добавляйте совместимый контент через «Установка контента», выбирая эту сборку.

Ожидаемый результат

Есть отдельная сборка, которая запускается с выбранным профилем; затем можно добавлять моды небольшими группами.

Если не получилось

Если игра не открывается, смотрите «Логи запуска» и «Диагностика». Сначала проверьте базовый запуск без новых модов, а не меняйте несколько настроек одновременно.

Безопасное восстановление

Перед модами, конфигами и обновлением мира сделайте копию папки saves. При проблеме отключите последнюю добавленную группу контента и повторите запуск.
